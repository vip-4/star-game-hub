為什麼使用靜態遊戲入口

相較於需要伺服器與打包工具的方案，單一靜態站臺在部署與維護上更單純。

載入速度快

五款遊戲都不依賴外部圖片、音檔或前端框架。首頁僅需少量 HTML、CSS 與各遊戲獨立的 JavaScript。

部署彈性高

整個目錄可直接放到 GitHub Pages、Cloudflare Pages 或任意靜態空間，不需要資料庫、快取或背景服務。

可索引與可引用

重要內容均為真實 HTML 文字，並以結構化資料標記遊戲清單與問答，方便搜尋引擎與生成式引擎摘要。

常見問題

以下問答同時以 JSON-LD 標記，可供搜尋引擎與生成式引擎引用。

星遊戲樂園收錄哪些遊戲？

目前收錄五款原創靜態遊戲：星耀拉霸 Star Spin（三轉輪老虎機，使用虛擬幣）、星節奏 Star Beat（四軌節奏遊戲）、星際跑者 Star Runner（無限跑酷遊戲）、星影解謎 Star Puzzle（分身平台解謎）與星際射手 Star Shooter（太空射擊）。五款都可在此頁直接進入遊玩。

玩這些遊戲需要註冊或付費嗎？

不需要。五款遊戲都是純前端靜態網頁，免註冊、免下載、無內購、無現金交易。星耀拉霸使用的是不具現金價值的虛擬幣，僅供娛樂。

這些遊戲可以在手機上玩嗎？

可以。五款遊戲都採用響應式設計。星耀拉霸提供觸控按鈕與高 DPI 畫面調整；星節奏提供四個觸控軌道按鈕；星際跑者提供大型觸控跳躍按鈕；星影解謎提供移動、跳躍、分身與回收觸控按鈕；星際射手提供滑動移動與點擊發射觸控操作。音效需由使用者首次點擊後才會解鎖。

遊戲使用了哪些第三方素材？

沒有。五款遊戲的圖形都由 Canvas 2D 繪製，音效由 Web Audio API 合成，沒有外部圖片、音檔、字型或遊戲引擎套件，因此載入快速，也避免素材授權問題。

這個首頁如何針對搜尋引擎與 AI 優化？

首頁使用語意化 HTML、完整的中繼資料與 Open Graph／Twitter Card，並以 JSON-LD 標記遊戲清單與常見問題；另提供 llms.txt 純文字摘要，方便生成式引擎擷取核心事實與引用。
