遊戲說明

鍵盤操作

  • ↑↓←→ 或 WASD：滑動合併
  • Z：撤銷一步　H：提示
  • R：重新開始　M：切換音效

觸控操作

  • 在畫面上滑動：往該方向合併
  • 新遊戲／撤銷／提示按鈕

遊戲規則

  • 相同數字相撞會合併加倍
  • 每次移動生成一個新方塊
  • 合成 2048 即獲勝，可繼續挑戰
  • 網格填滿且無法合併時遊戲結束

技術資訊

渲染
Canvas 2D 圓角網格與動畫，依裝置像素比縮放
音訊
Web Audio API 即時合成，首次互動後解鎖
功能
撤銷、提示、最佳分數（localStorage）
圖形
程序生成方塊配色與粒子，無外部圖片
無障礙
ARIA 標籤、狀態播報、完整鍵盤操作
