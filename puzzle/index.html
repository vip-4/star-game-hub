星影解謎 Star Puzzle：一款完全原創的 HTML5 分身解謎遊戲

星影解謎是一款單畫面平台解謎遊戲。玩家放置靜止的分身壓住壓力板， 讓擋路的雷射停止運作，再收集星星並抵達出口。 所有圖形由 Canvas 2D 繪製，音效由 Web Audio API 即時合成， 沒有外部素材、沒有後端，也不需要註冊或下載。

遊戲特色

以純前端技術達成流暢體驗，同時兼顧可索引內容與無障礙操作。

原創解謎機制

分身是靜止的實體，可以站在壓力板上，但不會幫你移動或開門。你必須規劃放置順序，用有限的次數同時滿足所有條件。

零外部素材

沒有精靈圖、沒有 MP3、沒有外接字型，也沒有使用任何第三方遊戲引擎。所有視覺元素由 Canvas 繪製，所有聲音由 Web Audio 合成。

無障礙與行動支援

提供鍵盤與觸控雙操作、ARIA 即時播報、清楚焦點樣式，並支援「減少動態效果」偏好設定。畫面會依裝置像素比調整。

玩法與操作

規則單純，但關卡設計需要一點思考。

  1. 開始遊戲。點擊「開始遊戲」或按 Enter，同時解鎖音效。
  2. 放置分身。站在壓力板上按 C，分身會留在原地持續壓住它。
  3. 關閉雷射。當同組壓力板都被壓住，對應雷射就會停止；按 X 可回收最後一個分身重新安排。
  4. 抵達出口。收集星星並走進右側出口，按 Enter 前往下一關。

常見問題

以下問答同時以結構化資料標記，方便搜尋引擎與生成式引擎摘要引用。

星影解謎在玩什麼？

玩家扮演一名星星特務，在單畫面關卡中移動與跳躍。關鍵機制是按 C 放置一個靜止分身：分身可以壓住壓力板，讓對應的雷射停止運作。玩家必須用有限的分身數壓住所有必要壓力板，再避開雷射抵達右側出口，並盡量收集每關三顆星星。

要怎麼操作星影解謎？

鍵盤使用 A/D 或左右方向鍵移動，W、上方向鍵或空白鍵跳躍，C 放置分身，X 回收最後一個分身，R 重來目前關卡，Enter 進入下一關。手機可使用畫面下方的觸控按鈕。

被雷射碰到或掉下去會怎樣？

會重新開始目前關卡，分身、壓力板與星星狀態都會重置。已在前一關取得的星星會保留，因此不會失去整體進度。

用了第三方遊戲引擎或素材嗎？

沒有。本遊戲是原創實作，沒有使用 GameJs、Phaser、PixiJS 等任何遊戲引擎，也沒有外部圖片、音檔或字型；圖形由 Canvas 2D 逐幀繪製，音效由 Web Audio API 即時合成。

可以在手機上遊玩嗎？

可以。介面採用響應式設計，並提供移動、跳躍、放置分身與回收分身的觸控按鈕。音效必須先點擊「開始遊戲」或「音效」按鈕才會解鎖，符合行動瀏覽器的自動播放限制。
