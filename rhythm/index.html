星節奏 Star Beat：一款完全原創的 HTML5 節奏遊戲

星節奏是一款四軌節奏遊戲，玩家在音符落到判定線時按下對應按鍵得分。 所有圖形由 Canvas 2D 繪製，音樂與音效由 Web Audio API 即時合成， 沒有外部素材、沒有後端，也不需要註冊或下載。

遊戲特色

以純前端技術達成流暢體驗，同時兼顧可索引內容與無障礙操作。

零外部素材

沒有圖片精靈圖、沒有 MP3、沒有外接字型。所有視覺元素由 Canvas 繪製，所有聲音由 Web Audio 合成，因此首屏只需少量 HTML、CSS 與 JavaScript。

流暢判定與動畫

使用請求動畫影格與時間軸驅動音符位置，搭配物件池管理粒子效果，避免頻繁配置物件造成卡頓，並依裝置像素比調整解析度。

無障礙與行動支援

提供鍵盤與觸控雙操作、ARIA 即時播報、清楚焦點樣式，並支援「減少動態效果」偏好設定，讓不同裝置與使用情境都能遊玩。

玩法與計分

規則單純，適合首次接觸節奏遊戲的玩家。

  1. 開始遊戲。點擊「開始遊戲」解鎖音效並啟動譜面。
  2. 對應軌道。四條軌道由左至右對應 D、F、J、K，也可用方向鍵或觸控按鈕。
  3. 精準擊打。音符通過判定線時按下，誤差越小得分越高。
  4. 查看結算。曲子結束後顯示最終分數、最大連擊與準確率。

常見問題

以下問答同時以結構化資料標記，方便搜尋引擎與生成式引擎摘要引用。

星節奏需要註冊或下載嗎？

不需要。星節奏是純前端的靜態網頁遊戲，開啟首頁即可遊玩，沒有帳號系統、沒有下載程序，也沒有內購。

要怎麼操作星節奏？

使用鍵盤 D、F、J、K 四鍵，或方向鍵左、下、上、右，對應畫面上的四條軌道。手機使用者可直接點觸畫面下方的四個軌道按鈕。當音符落到判定線時按下對應鍵即可得分。

遊戲的音效與圖形是哪裡來的？

全部由程式即時產生。圖形使用 Canvas 2D 繪製，音樂與打擊聲由 Web Audio API 合成，沒有任何外部音檔、圖片或字型請求，因此載入速度快，也避免第三方素材授權問題。

判定方式與計分規則為何？

音符與判定線的誤差在 70 毫秒內為 Perfect 得 300 分，140 毫秒內為 Good 得 100 分，超過 180 毫秒未按下則為 Miss 並中斷連擊。連續命中可累積 Combo，結算時顯示準確率。

可以在手機上遊玩嗎？

可以。介面採用響應式設計，並提供四個觸控軌道按鈕。音效必須先點擊「開始遊戲」或「開啟音效」才會解鎖，這符合 iOS Safari 與多數行動瀏覽器的自動播放限制。
