星際跑者是一款無限跑酷遊戲。星星快遞員會自動向前奔馳， 玩家只需掌握跳躍時機，跨越平台間的空隙、收集星芒並閃避隕石。 所有圖形由 Canvas 2D 繪製，音效由 Web Audio API 即時合成， 沒有外部素材、沒有後端，也不需要註冊或下載。

遊戲特色

以純前端技術達成流暢體驗，同時兼顧可索引內容與無障礙操作。

零外部素材

沒有精靈圖、沒有 MP3、沒有外接字型。所有視覺元素由 Canvas 繪製，所有聲音由 Web Audio 合成，首屏只需少量 HTML、CSS 與 JavaScript。

流暢的跑酷手感

採用時間軸驅動的物理與程序生成平台，按住跳躍鍵可延長上升時間；速度隨距離平緩提升，粒子效果由固定大小物件池管理以避免卡頓。

無障礙與行動支援

提供鍵盤與觸控雙操作、ARIA 即時播報、清楚焦點樣式，並支援「減少動態效果」偏好設定。畫面會依裝置像素比調整，上限兩倍以避免過度繪製。

玩法與計分

規則單純，但想跑得遠需要掌握節奏。

  1. 開始遊戲。點擊「開始遊戲」或按空白鍵，同時解鎖音效。
  2. 掌握跳躍。角色自動前進，遇到空隙就跳；按住跳躍鍵可跳得更高更遠。
  3. 收集與閃避。碰觸星芒可加分，撞上紅色隕石或跌落畫面外即結束。
  4. 刷新紀錄。最佳分數保存在本機瀏覽器，可按 R 立即再玩一次。

常見問題

以下問答同時以結構化資料標記，方便搜尋引擎與生成式引擎摘要引用。

星際跑者在玩什麼？

玩家操控一名星星快遞員，在浮空平台間自動向右奔馳。按跳躍鍵跨過空隙，收集星芒加分，並閃避阻擋在平台上的隕石。跑得越遠速度越快，跌落星海或撞上隕石即結束。

要怎麼操作星際跑者？

鍵盤使用空白鍵、方向上鍵或 W 跳躍，按住可跳得更高；P 或 Esc 暫停，R 重新開始，M 切換音效。手機可直接點觸畫面或「跳躍」按鈕，一樣支援按住跳更高。

分數是怎麼計算的？

每前進 12 個世界單位獲得 1 分，每收集一枚星芒額外獲得 50 分。最佳分數會儲存在瀏覽器本機，下次開啟時仍會顯示。

遊戲使用了第三方素材或遊戲引擎嗎？

沒有。圖形由 Canvas 2D 逐幀繪製，音效由 Web Audio API 即時合成，沒有外部圖片、音檔、字型，也沒有使用任何遊戲引擎套件，因此沒有素材授權問題。

可以在手機上遊玩嗎？

可以。介面採用響應式設計，並提供大型觸控跳躍按鈕。音效必須先點擊「開始遊戲」或「音效」按鈕才會解鎖，這符合 iOS Safari 與多數行動瀏覽器的自動播放限制。
