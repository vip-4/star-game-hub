遊戲說明

鍵盤操作

  • ←→ 或 AD：沿邊緣移動
  • Space / W / ↑：發射
  • Shift / S / ↓：翻轉到對側
  • P / Esc：暫停　M：靜音

觸控操作

  • ◀ ▶ 按鈕：沿管道邊緣移動
  • ● 按鈕：按住連續發射
  • ⇄ 按鈕：翻轉到對側軌道

遊戲機制

  • 敵人從管道深處沿軌道向外爬
  • 抵達邊緣的敵人會變成沿邊爬行的蜘蛛
  • 翻轉可瞬間到對側避開危機
  • 核心生命歸零即遊戲結束

技術資訊

渲染
Canvas 2D 透視投影，依裝置像素比縮放
音訊
Web Audio API 即時合成，首次互動後解鎖
圖形
程序生成管道網格與幾何敵機，無外部圖片
關卡
程序生成波次與首領，難度遞增
無障礙
ARIA 標籤、完整鍵盤操作、prefers-reduced-motion
